# Pavithra Philomena — Portfolio

Personal developer portfolio showcasing projects in Artificial Intelligence, Machine Learning, Data Science, and Full Stack Web Development.

## 🚀 Features
- **Design & UI**: High-impact modern aesthetics with Cosmic Dark and Crisp Light themes, glassmorphic cards, and smooth micro-animations.
- **Projects**:
  - **OCR Medical Prescription Digitizer**: Alonzo AI healthcare system digitizing handwritten records using PaddleOCR & Tesseract with high accuracy.
  - **Multilingual Telemedicine Voice Bot**: Voice-driven patient interaction bot built on FastAPI and Whisper.
  - **Punarjanam (SVIT Hackathon 2nd Prize)**: Integrated disaster relief and emergency coordination platform.
  - **Bilingual Legal Assistant**: Legal query simplification with multilingual document retrieval.
- **Stack**: HTML5, Vanilla CSS, JavaScript, React, Django, Python, SQL.

## 📦 Deployment
Configured for zero-config static deployment on [Vercel](https://vercel.com).
